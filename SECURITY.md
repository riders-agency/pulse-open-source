# Безопасность

Не сообщайте об уязвимостях с ключами или данными пользователей в публичном issue.
Используйте приватное сообщение об уязвимости через вкладку Security репозитории,
если этот канал включён владельцем. Если канал недоступен, сначала запросите у
владельца приватный канал связи без публикации деталей эксплуатации.

Ключи провайдеров хранятся на сервере в зашифрованном виде. Настоящие `.env`,
приватные ключи, дампы, вложения пользователей и рабочие логи не входят в репозиторий.
Для каждой установки создавайте собственные ключи и пароли; примеры рассчитаны
только на локальную разработку.

При обнаружении опубликованного секрета сначала отзовите его у провайдера,
затем удалите его из актуального дерева и истории. Одного удаления строки мало.
