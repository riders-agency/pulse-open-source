# Проверки версии от 9 ноября 2026

Проверки используют синтетические данные. Приёмка включает код, чистую установку
базы и реальные действия в интерфейсе.

- Go: полный набор тестов с PostgreSQL и race, vet, staticcheck, fuzz smoke,
  сборка команд; govulncheck не находит известных уязвимостей.
- Python: Ruff, mypy и 132 теста, включая PostgreSQL-checkpoint.
- Web: ESLint, ограничения размера модулей, TypeScript, production build и CSS.
- Браузер: восемь продуктовых сценариев и два сценария технической витрины.
  Проверены черновик чата при сбое, мобильное меню, удаление и восстановление
  задач, отключение шага сценария, клавиатура ИИ-чата, повтор отправки виджета
  и банковский черновик с потерей ответа после сохранения.
- Банковские черновики: конкурентные записи, чужой проект, права чтения и записи,
  закрытая оплата, запрет подмены суммы и статуса.
- OpenAPI: 240 операций; воспроизводимая генерация типов и клиента. Описаны
  пропущенные ответы об ошибках. Рекомендательный lint отдельно отмечает
  WebSocket с корректным ответом HTTP 101 и публичные GET без ошибок 4xx.
  Эти предупреждения не скрываются, фиктивные HTTP-ответы не добавляются.
- Protobuf: формат, lint, воспроизводимая генерация и descriptor baseline.
- Чистая база: установка до версии 115, повторное применение, откат и восстановление.
- Gitleaks: публичное дерево и история без находок. Единственное точное исключение —
  буквальный пример `PROJECT_SECRET_HERE` в инструкции вебхука.

## Контроль архитектуры и доступа

Архитектурная проверка проходит без исключений. Удалены старый исполняющий путь
ИИ в Go, неиспользуемый код и просроченные разрешения обходить границы модулей.
Проверены 20 контрактов чтения: они не обновляемы и не содержат секретных столбцов.
Команды принадлежат модулям данных; транзакцию открывает прикладной слой.
См. [решение о границах](architecture/controlled-module-boundaries.md).

Интеграционные тесты проверяют активное членство, ограничения API-ключей,
аудитора, отключение сотрудника и текущий allowlist. Восемь одновременных
подтверждений создают один объект. Ошибка сохранения результата подтверждения
откатывает бизнес-изменение. Уровень риска инструмента нельзя понизить запросом.

В браузерное постоянное хранилище не записываются bearer-токены. WebSocket
использует cookie без ключа в URL. Заголовкам IP доверяем только от явно
настроенного прокси. Трассировка модели ограничена и проходит проверку Go.

## Демонстрация

`/tech` проверен без входа, с клавиатуры и на ширинах 320–1440 px.
Граф экспортирован из исполняемого LangGraph; проверка выявляет расхождение
экспорта с Python. В чате показаны пройденные узлы, инструменты, ожидание человека
и расход из ответа провайдера. [Описание контроля ИИ](AI_CONTROL.md).

Чат на видео использует вымышленных Ксению и Дениса и воспроизводимый сбой API.
Редактор сценария и банковский черновик сохраняют данные в настоящую PostgreSQL.
Банковская интеграция пока ограничена контрактом адаптера и черновиками.
Внешняя доставка сообщений, выпуск банковского счёта и голосовая связь
этой приёмкой не подтверждаются.

Публичное демо использует APInet и изолированные проекты гостей. Проверка
изоляции запрещает чтение чужой задачи и изменение подключений. Модельные
обращения ограничены квотой; интеграционные ключи остаются на сервере.

Живой браузерный сценарий прошёл: совет `gpt-4.1-mini` через APInet → реальные
входные/выходные токены и граф → предложение `task.create` → ожидание человека →
высокий приоритет → подтверждение → перезагрузка чата с сохранённой трассировкой
→ открытие созданной задачи. Ошибок страницы или API не было.

## Публичный репозиторий

GitHub Actions отключены по решению владельца. Проверки запускаются локально;
их инструкции доступны в репозитории. Публичная история начинается с чистого
экспорта и не наследует закрытые коммиты. См. [аудит истории](REPOSITORY_AUDIT.md).

## SDK 0.1

TypeScript/JavaScript и Python: тесты транспорта прошли, включая ошибки,
запрет редиректов и отсутствие автоматического повторения записей. TypeScript
также проверяет таймаут и отмену. TypeScript, Python, Go и PHP прошли на живом демо
вход, создание/изменение/архив/восстановление задач и создание задачи через
ИИ-предложение с явным подтверждением. Go: сборка и `go vet` прошли.

OpenAPI Generator 7.20.0 с закреплённым SHA-256 успешно создал клиентов Go, PHP,
C#, Rust, Swift, Dart и Ruby. 16 операций SDK сверены с реестром
маршрутов приложения. Проверка контракта генератором прошла. SSE не входит в SDK.

PHP: 27 файлов прошли синтаксическую проверку, зависимости установлены из
зафиксированного Composer lockfile.
C#, Rust, Swift, Dart и Ruby: генерация прошла; компиляция и живые вызовы
в этих средах не выполнялись. Python wheel/sdist и TypeScript tarball собраны.

Фреймворки: Laravel 13.40.0, Symfony 7.4.23, NestJS 12.4.0, Express 5.3.0,
Fastify 5.12.8, H3 2.0.8, FastAPI 0.162.2, Django 6.1.3, Flask 3.1.3.
Проверены request scope двух пользователей и отклонение анонимного запроса.
Go-адаптер: race/vet и перенос отмены запроса. TypeScript: отдельный тест
готового HTTP-обработчика, 401/405 и отсутствие общего токена.
Код и команды проверок включены в `sdk/frameworks/tests`. Рецепты React/Vue/
Angular/Svelte и нативных UI не объявляются запущенными тестами этих приложений.

SDK опубликованы как исходники и устанавливаемые GitHub-релизы.
PHP SDK 0.1.0 также опубликован в [Packagist](https://packagist.org/packages/riders-agency/pulse-sdk).
Проверена установка Composer из общего каталога без VCS-репозитория, автозагрузка
и создание клиента API. В каталоги npm/PyPI пакеты ещё не отправлены:
для этих сервисов требуется авторизация владельца. pip из Git и npm из tarball
доступны без публикации в каталогах.
