# ИИ-отделы внутри сценариев Pulse

Демо-вход создаёт отдельную компанию и проект. Рабочий сценарий «Входящая почта → ИИ-отделы» находится в `/project-workflows`, открывается обычным редактором и сохраняет исполнения в общем журнале. Старый `/demo` только перенаправляет на вход в компанию; отдельного приложения и iframe нет.

Серверный worker опрашивает учебный ящик каждые 30 секунд, независимо от открытого браузера. Пустой опрос не вызывает модель. Каждое новое письмо получает один запуск; ключ доставки защищает от повторного добавления. Кнопка «Добавить учебное письмо» кладёт письмо в очередь, а не запускает его немедленно. Опрос можно приостановить и возобновить.

Расписание привязано к исходному времени следующей проверки: задержка worker
не добавляется к каждому следующему интервалу. После простоя пропущенные интервалы
пропускаются; накопившиеся пустые проверки не запускаются подряд.

Путь исполнения: входящее письмо → классификация → передача в отделы → подготовка страницы → черновик счёта → решение человека → сохранение. Классификация и подготовка текста выполняются Python/LangGraph через защищённый gRPC, с обращением к модели через Go ModelGateway. Токены берутся из ответа провайдера. Модель возвращает только данные проверяемой схемы; сумму счёта и права она не определяет.

При возобновлении ядро восстанавливает результаты уже завершённых шагов: модель
не вызывается повторно, а сохраняется ровно тот черновик, который увидел человек.

Go отвечает за принадлежность компании и проекта, очередь, версии сценария, журнал шагов и возобновление. До подтверждения результат не сохраняется. Отклонение заканчивает запуск без публикации. Решение проверяется по проекту и текущему состоянию запуска; повторное решение возвращает конфликт. Сохранение результатов идемпотентно.

Для каждого экземпляра этого демо-сценария в базе остаётся максимум 30 исполнений. Перед новым запуском удаляется самое старое завершённое исполнение вместе с зависимыми шагами, событиями и результатами. Ожидающие человека и работающие запуски не удаляются: если самый старый из 30 ещё не завершён, новые письма ждут в очереди. Другие сценарии этой политикой не затрагиваются. Очередь учебных писем также ограничена 30.

Почтовый ящик, сайт и заказ учебные. Внешний IMAP, CMS и банк не подключены. Страница и черновик счёта сохраняются в PostgreSQL и видны в демо-компании. Произвольные внешние отправки в демо запрещены.

## Проверка

- `OFFICE_TEST_DATABASE_URL=... go test -race ./apps/api/internal/runtime/kernel -run Office -v` — только отдельная база с `office_test` в имени: изоляция, дедупликация, интервал, подтверждение и лимит истории.
- `uv run --directory apps/ai-agent pytest src/pulse_agent/tests/test_workflow_agent.py` — ограниченные действия LangGraph, схемы результата и статистика модели.
- `PULSE_BASE_URL=... pnpm --dir apps/web test:e2e e2e/demo.spec.ts` — реальный вход, серверный опрос, подтверждение, отклонение, журнал и мобильный интерфейс.
