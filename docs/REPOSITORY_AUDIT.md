# Проверка публичного снимка — 9 ноября 2026

## Что публикуется

`riders-agency/pulse-open-source` опубликован отдельным репозиторием. По решению
владельца публикация 0.2 сведена к одной ветке `main` с одним начальным коммитом;
тег `v0.2.0` указывает на тот же снимок. Старый тег и релиз 0.1 удалены.
Закрытая рабочая история, старые ветки, теги, pull request
и кешированные объекты прежнего репозитория сюда не переносятся.

Экспорт включает исходники, контракты, общие каталоги БД, локальные проверки,
документацию и демонстрационные медиа с вымышленными данными. `PUBLIC_EXPORT.json`
описывает состав. Рабочие настройки, ключи, дампы, журналы и служебные миграции
конкретных компаний исключены. Автор коммита использует публичный деловой контакт.

## Метод проверки

- Gitleaks 8.30.1: полный публикуемый каталог, затем вся новая Git-история.
  Стандартные правила включены; единственное точное исключение — буквальный
  пример `PROJECT_SECRET_HERE` в генераторе инструкции вебхука.
- Дополнительный поиск личных адресов, телефонов, IP, домашних путей, файлов
  конфигурации и приватных ключей; просмотр SQL-вставок и метаданных Git.
- Проверка изображений и записей интерфейса: только синтетические сценарии.
- Рабочие значения ключей демо отдельно сопоставлены с собранным веб-приложением
  на сервере, без вывода самих значений. Совпадений не обнаружено.

Похожие на действующие секреты в проверенном снимке не обнаружены. Совпадения
тестовых телефонов и адресов используют примеры. Публичный деловой контакт
сохранён намеренно. В начальной миграции нет пользователей, клиентов и интеграций.

## Предыдущий репозиторий

Перед публикацией проверены все доступные ветки, теги и ссылки PR прежнего
репозитория, а также 70 файлов журналов из 15 запусков Actions. Действующие
секреты сканером не обнаружены; найдены исторические личные метаданные
и адреса инфраструктуры. Ветки и тег очищены с согласия владельца.

GitHub продолжал открывать старые объекты по известному SHA даже после замены
веток. Поэтому прежний репозиторий оставлен закрытым, а публичная версия
создана без его истории. Старые журналы Actions сохранены в закрытой резервной
копии и удалены с GitHub.

## Демо и границы аудита

Демо работает с отдельной базой и новыми внутренними ключами. Данные рабочей
установки не копируются. Доступ двух гостей проверяется независимо; провайдер
модели доступен только через серверный шлюз. [Ограничения демо](PUBLIC_DEMO.md).

GitHub используется как хранилище: Actions отключены, workflow-файлов нет.
Проверки выполняются локально и не означают автоматической проверки будущих
коммитов. Любое следующее изменение нужно проверять перед публикацией.

Это результат конкретных проверок, а не гарантия отсутствия любого возможного
секрета или уязвимости. Чужие клоны, недоступные объекты GitHub и закрытая
рабочая история не входят в публичный снимок и не объявляются очищенными.
