# Descriptor Baselines

`ai_agent_v1.binpb` is the committed descriptor baseline for `contracts/proto/ai_agent/v1`.

It is generated by the pinned `buf` version from `scripts/check-proto-contracts.sh`:

```bash
buf build contracts/proto -o contracts/proto/descriptors/ai_agent_v1.binpb
```

CI compares pull requests against the descriptor from `origin/main` when it exists, then verifies that the committed baseline matches the current proto sources.
