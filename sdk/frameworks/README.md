# Pulse в популярных фреймворках

SDK остаётся клиентом API, а фреймворк управляет запросом и авторизацией приложения.
Адаптер создаётся отдельно для каждого пользователя. Сервер Pulse проверяет
права на проект; модель и внутренние gRPC-шлюзы не открываются клиентам SDK.

- [Next.js, NestJS, Express, Fastify, Nuxt и SvelteKit](typescript.md): готовый
  обработчик чтения задач и создание клиента из пользовательской авторизации.
- [React, Vue, Angular и Svelte](frontend.md): примеры интерфейса поверх своего
  серверного маршрута; серверные API-ключи в браузер не передаются.
- [FastAPI, Django и Flask](python.md): адаптер request scope без зависимостей
  ядра SDK от выбранного фреймворка.
- [Laravel и Symfony](php.md): provider с автоматическим обнаружением,
  конфигурация контейнера и отдельный клиент на запрос.
- [Gin, Echo, ASP.NET Core, Rails, Axum, Actix, Flutter и SwiftUI](native.md):
  подключение нативного клиента и границы владения пользовательской сессией.

Готовые адаптеры и примеры имеют разные уровни проверки. Исполняемые тесты
TypeScript/Python проверяют отсутствие смешения пользователей. Для Laravel
и Symfony проверяются регистрации контейнера и авторизация. Остальные рецепты
показывают интеграцию; они не объявляются тестами всех версий фреймворков.

Сессии и токены должны поступать из авторизации вашего приложения. Пример
`Bearer` относится к сессии конкретного пользователя, а не к общему ключу
владельца. Общий служебный ключ допустим только в доверенных серверных заданиях
с ограниченными правами; не используйте его в публичном прокси для всех гостей.

Никакой адаптер не подтверждает предложение ИИ автоматически. Для записи
пользователь сначала видит карточку, затем приложение вызывает метод подтверждения.

## Повторение проверок

- Node: соберите TypeScript SDK, затем `pnpm --dir sdk/frameworks/tests/node install --frozen-lockfile`
  и `node sdk/frameworks/tests/node/check.mjs`.
- Python: установите `sdk/frameworks/tests/python/requirements.txt` в отдельное
  окружение, затем `PYTHONPATH=sdk/python/src python sdk/frameworks/tests/python/check.py`.
- PHP: `composer install --working-dir=sdk/frameworks/tests/php`, затем
  `php sdk/frameworks/tests/php/check.php`. Нужны PHP 8.3, mbstring, dom и xml.
- Go: `go test -race ./...` из `sdk/generated/go` с `GOWORK=off`.

Проверки используют локальный тестовый сервер и вымышленные сессии. Рабочие
ключи и внешние модельные вызовы не нужны.
