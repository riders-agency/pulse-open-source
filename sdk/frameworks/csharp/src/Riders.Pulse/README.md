# Pulse SDK · C# / ASP.NET Core

Клиент API v1: задачи, ИИ-сессии и явное подтверждение предложений.
Сгенерирован OpenAPI Generator 7.20.0 из общего контракта SDK.

## Сборка

Из корня C#-пакета:

```bash
dotnet restore src/Riders.Pulse/Riders.Pulse.csproj
dotnet pack src/Riders.Pulse/Riders.Pulse.csproj -c Release
```

Пакет на NuGet не опубликован; сборка и интеграционный вызов в среде .NET
не выполнялись. Используйте локальную project reference либо собранный NuGet.

## Подключение

Типизированные интерфейсы находятся в `Riders.Pulse.Api`, модели — в
`Riders.Pulse.Model`. Методы возвращают типизированный результат со статусом;
обрабатывайте неуспешный HTTP-ответ явно.

`AddApi` из `Org.OpenAPITools.Extensions` регистрирует HTTP-клиенты. Для серверного
задания задавайте origin и ограниченный токен из секретов окружения. Для запросов
разных пользователей нужен свой scoped token provider: не меняйте общий токен
singleton между запросами. Передавайте токен отмены текущего HTTP-запроса.

Установите HTTPS, таймаут и запрет редиректов. Не добавляйте универсальный retry
для всех методов: после неопределённого результата записи сначала прочитайте
задачу или сессию. Подтверждение ИИ должно следовать явному решению пользователя.
Не выводите тела ответов авторизации и необработанные исключения в публичные логи.
