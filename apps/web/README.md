# Riders Pulse — веб-интерфейс

Next.js 16 и React: компании и проекты, сценарии, задачи и процессы, клиенты,
финансы, чат оператора и ИИ-сотрудник. Интерфейс использует русские подписи,
общие элементы управления и адаптивное меню.

## Запуск

Из корня репозитория, при уже запущенном локальном Go API:

```bash
pnpm --dir apps/web install --frozen-lockfile
RP_API_PROXY_URL=http://127.0.0.1:9820 pnpm --dir apps/web exec next dev -p 9821
```

Браузер обращается к `/api/v1` на том же адресе, что и интерфейс. Локальный
Next.js перенаправляет запросы на Go. В production эту роль выполняет reverse
proxy; `RP_API_PROXY_URL` тогда не нужен. Ключи модели и банка не входят в
публичные переменные сборки и никогда не передаются в Python через браузер.

## Структура

- `src/features` — экраны, модели состояния и API конкретных функций.
- `src/components/ui` — общие элементы управления и доступные диалоги.
- `src/lib/api/generated` — типы и клиент из OpenAPI.
- `src/styles` — общие переменные оформления и стили модулей.
- `e2e` — браузерные проверки; product-polish допускает только локальный адрес.

## Проверки

```bash
pnpm --dir apps/web lint
pnpm --dir apps/web typecheck
pnpm --dir apps/web build
```

Для браузерных тестов нужны Google Chrome и отдельная локальная установка с
синтетическим пользователем. Пароль задаётся через `PULSE_OWNER_PASSWORD`.
Тестовые ответы внешнего чата не подтверждают доставку реальным посетителям.
