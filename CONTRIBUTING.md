# Вклад в Riders Pulse

Воспроизведите проблему на отдельной локальной базе с вымышленными данными.
Опишите ожидаемое и фактическое поведение, ширину экрана для ошибок интерфейса
и минимальные шаги воспроизведения. Не прикладывайте ключи, cookies или данные
клиентов.

Изменения должны сопровождаться подходящими проверками. Для изменения API
обновляйте OpenAPI; для межпроцессного контракта — protobuf и оба клиента.
Права и бизнес-правила остаются на сервере. Изменения схемы после публичной
начальной миграции добавляются новыми парными миграциями.

В PR укажите конкретное изменение, выполненные проверки и оставшиеся ограничения.
GitHub используется как хранилище: Actions отключены. Запускайте проверки
локально и указывайте результат с проверенным коммитом. Существующие ошибки
локальных проверок не скрывайте; не меняйте критерии ради успешного результата.
